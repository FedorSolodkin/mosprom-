Mosprom Wiki

Сервис, который сам подбирает параметры FDM-печати: что входит в задачу, из каких этапов она состоит и какие готовые решения есть для каждого этапа.

Что в задаче

Нужен сервис с чатом. Пользователь загружает модель (STL), фото и пишет, что хочет получить. Сервис сам выбирает настройки печати, делает G-код, отправляет его на нужный принтер и следит за печатью.

Вход

Файл STL, фото, текстовый запрос.

Выход

Настройки печати, готовый G-код, запущенная печать на принтере из парка.

Термины

STLфайл с 3D-моделью.
Слайсерпрограмма, которая режет модель на слои и делает G-код (Cura, PrusaSlicer, OrcaSlicer).
G-кодфайл с командами, которые выполняет принтер.
FDMпечать пластиковой нитью, расплавленной в сопле.
5D-печатьстол и сопло наклоняются, слои идут не плоско.
MCP-серверпрограмма, через которую ИИ получает команды для управления программами и принтерами.

Статус: «Есть готовое» значит, что можно взять существующий инструмент. «Пишем сами» значит, что готового решения не найдено. Целиком всю цепочку не закрывает ни одно найденное решение; ближе всего Kiln (67% функций).

Этапы и готовые решения

По каждому этапу: что это, три готовых решения и подробная статья. Число рядом с решением — оценка из таблицы, от 0 до 5.

01Чат и связь с ИИ Есть готовое

Пользователь пишет в чат. ИИ должен уметь управлять слайсером и принтером, для этого ему дают набор команд. Сервер, который публикует эти команды, называется MCP-сервером.

Вход: Запрос пользователя (текст, фото, STL). Выход: Команды для ИИ.

Готовые решения

MCP SDK (Python)MIT

Библиотека, на которой пишется такой сервер. Сама задач печати не решает.

3,95Источник
mcp-3D-printer-serverGPL-2.0

Готовый сервер: работает со многими принтерами и слайсерами, перед стартом просит подтверждение. Умного подбора параметров нет.

3,60Источник
PrusaMCPMIT

Готовый сервер для PrusaSlicer: советует профиль и проверяет модель. Проект помечен как неактивный.

3,35Источник
Подробная статья

Готовые MCP-серверы уже умеют «дать ИИ руки»: запускать слайсер и командовать принтером. Решения о параметрах при этом принимает подключённая LLM, а не сам сервер (исключение — PrusaMCP с функцией рекомендации профиля).

Проект Что делает Принтеры и слайсеры Лицензия и зрелость
mcp-3D-printer-server Инструменты: статус принтера, загрузка G-кода, старт и отмена печати, температура, slice_stl, print_3mf, простые правки STL (scale_stl, lay_flat). Перед стартом печати и нагревом требует подтверждения человека OctoPrint, Klipper/Moonraker, Bambu Lab (больше всего проверен), PrusaLink, Duet, Repetier, Creality; PrusaSlicer, Slic3r, OrcaSlicer, CuraEngine, Bambu Studio GPL-2.0, npm 1.2.12; тип принтера задаётся переменной, управление парком в описании не показано
Cura MCP Плагин, через который ИИ управляет Cura: загрузка и поворот моделей, настройки, нарезка, пакетная нарезка, сравнение времени, оптимизация ориентации, база истории печати. Есть сценарии с подтверждением Только Cura (5.11+); принтер-бэкенды в README не перечислены Проприетарная; требует отдельный MCP-Link; всё локально
PrusaMCP 17 инструментов: анализ сетки, проверка пригодности к печати, recommend_profile (по намерению, соплу, материалу с обоснованием каждой настройки), нарезка, постобработка G-кода, загрузка, обратная связь Только PrusaSlicer; PLA, PETG, ABS, ASA, TPU, Nylon, PC; OctoPrint и PrusaConnect MIT, v1.0.0 (февраль 2026); в каталоге помечен как неактивный (по пересказу); логика рекомендаций не раскрыта
Hermes-Skills (Flashforge) Навыки для агента Hermes: нарезка в OrcaSlicer, исправление проблем G-кода Flashforge, загрузка и запуск, учёт до 4 катушек; отдельный навык превращает наброски в OpenSCAD Только Flashforge AD5X; один принтер, без очереди Открытый, бесплатный, демо-проект (сентябрь 2026)

Как это устроено. Сервер публикует инструменты с описанием, LLM выбирает нужный и передаёт аргументы. Вызов slice_stl запускает консольный слайсер в фоне, а вызовы start_print и get_printer_status — API принтера (OctoPrint, Moonraker и др.). Нарезает модель именно слайсер; разные слайсеры дают разный G-код из-за разных алгоритмов и профилей.

Что брать. mcp-3D-printer-server — база для связи с принтерами и слайсерами (но лицензия GPL: лучше запускать как отдельный сервис). PrusaMCP — пример того, как оформить рекомендацию профиля с объяснением. Cura MCP закрыт и привязан к рабочему столу — для серверной сборки не подходит.

Ограничения. Автоматический подбор настроек под цель в этих серверах, кроме PrusaMCP, не описан; по печати на нескольких принтерах одновременно данных нет.

02Получение 3D-модели Частично

Если у пользователя нет готовой модели (файла STL), её нужно создать по тексту или фото. Есть два пути: нейросеть рисует сетку целиком или ИИ пишет код, который строит деталь с точными размерами.

Вход: Текст, фото. Выход: Файл STL.

Готовые решения

CadQuery + LLMApache-2.0

ИИ пишет код, код строит деталь. Размеры точные. Органические формы получаются плохо.

3,70Источник
MeshyПлатный сервис

Из текста или фото делает модель примерно за минуту. Точных размеров нет.

3,15Источник
Hunyuan3D (локально)Открытая модель

Работает у себя, без облака. Нужна видеокарта.

3,20Источник
Подробная статья

Есть два лагеря: меш-генераторы (быстрые, для фигурок, но без точных размеров) и «код → CAD» (LLM пишет OpenSCAD или CadQuery, точные размеры, но только простые детали). Для функциональных деталей подходит второй лагерь.

Решение Что умеет Цена и лицензия Заметки
Meshy Текст или фото → модель примерно за минуту; заявлены проверка герметичности и толщины стенок, авторемонт, разбиение крупных моделей, цвета для Bambu AMS; экспорт STL/3MF/OBJ; плагины для Bambu Studio, OrcaSlicer, Cura и др. Решение Подход Выход Зрелость
PrintPal CAD agent Чат-агент пишет параметрический OpenSCAD (BOSL2, MCAD); заявлена проверка печатибельности STL, 3MF, STEP Промо-страница (2026-08-07), платный (кредиты); ограничения не названы

Kiln Текст или набросок → генерация → проверка → нарезка → печать; провайдеры OpenSCAD и Meshy/Tripo/Stability/Gemini; фото только как рельеф на поверхности STL, G-код AGPL-3.0, без бенчмарков

Главный вывод. Для нашего проекта генерация — необязательный бонус: условие кейса даёт готовую STL. Если делать, то функциональные детали — через CadQuery или OpenSCAD с автоматической проверкой сетки, а фотореалистичные фигурки — через внешний сервис (Meshy, Tripo, Hunyuan3D).

Ограничения. Ни один измеренный тест пригодности к печати не найден у меш-генераторов: цифры — вендорские. Для «код → CAD» сама проблема — слабое пространственное мышление LLM (в трёх источниках названо прямо). Статья с «69,3% точного совпадения» для Text-to-CadQuery упомянута в обзоре Canterbury, саму статью мы не читали.

03Проверка и починка модели Есть готовое + пишем сами

Файл STL проверяют: нет ли дыр, какие размеры и объём. Битую модель чинят. Расчёт нависаний и тонких стенок готовым модулем не закрыт, его надо писать.

Вход: Файл STL. Выход: Проверенный STL и отчёт.

Готовые решения

trimeshMIT

Проверка целостности, размеры, объём, простой ремонт.

4,25Источник
pymeshfixAGPL-3.0

Чинит модели с дырами. Лицензия требует открывать код.

3,10Источник
numpy-stlBSD-3

Читает и пишет STL, считает объём. Не чинит.

3,45Источник
Подробная статья

Для анализа геометрии и починки сетки есть зрелые библиотеки в открытом доступе; готового модуля «найти нависания, тонкие стенки, подбрать ориентацию» на базе этих библиотек нужно дописывать самим (частично это есть в PrusaMCP, Meshy, Cura MCP).

Библиотека Что умеет Лицензия и версия Ограничения
trimesh Загрузка и анализ сеток: проверка is_watertight, объём и центр масс, разбиение на компоненты, срез плоскостью, простые исправления нормалей и небольших дыр, экспорт STL MIT; 5.1.1; статус Beta Ремонт только простых дефектов; булевы операции требуют Manifold3D или Blender
pymeshfix Ремонт «битых» сеток в единую замкнутую поверхность (обёртка MeshFix): clean_from_file, MeshFix(v, f).repair(), заполнение маленьких границ 0.18.1; лицензия: в метаданных AGPL-3.0, в README — GPLv3 с коммерческой лицензией; оба варианта «заразные» Предполагает одно замкнутое тело; на CAD-сетках может дать грубый результат
numpy-stl Чтение и запись STL (бинарный и ASCII), повороты, смещения, массовые свойства (объём, центр тяжести) BSD-3-Clause; по данным PyPI JSON версия 4.1.1 (страница проекта читалась как 4.0.1) Нет проверки герметичности и ремонта
FullControl GCode Не слайсер и STL не читает: описываете траекторию в Python, получаете G-код GPLv3; 0.1.2 (2025), один майнтейнер Структура репозитория может меняться; подходит для произвольных траекторий, в том числе экспериментов с 5D

Главный вывод. Связка trimesh + pymeshfix закрывает проверку и починку; нависания, тонкие стенки и ориентацию считает ваш код поверх них. Внимание: pymeshfix имеет копилефт-лицензию (AGPL/GPL), для коммерческого закрытого продукта нужна коммерческая лицензия или другой ремонтер; для хакатона это не проблема.

Что дописывать самим. Расчёт углов нависаний (через нормали граней в trimesh), поиск тонких стенок, оценку объёма поддержек и выбор ориентации перебором поворотов.

04Подбор параметров печати Пишем сами

Нужно выбрать температуру, высоту слоя, заполнение и скорость под цель пользователя: прочность, внешний вид, скорость. Это самое слабое место рынка: готовых решений мало, и все ограничены.

Вход: Модель, цель, материал, принтер. Выход: Набор настроек.

Готовые решения

slicer-copilotApache-2.0

ИИ предлагает правки под цель и объясняет их. Работает только с Bambu Studio, проект экспериментальный.

2,75Источник
CMU: LLM как эксперт по настройкеСтатья, кода нет

Идея: слайсер оценивает результат, ИИ подсказывает, что менять. Среди найденных подходов самый сильный, но готового кода нет.

2,75Источник
Ask The NozzleСервис

Принимает фото дефекта и проверяет модель до печати. Сведения только из блога самих авторов.

2,50Источник
Подробная статья

Это главное «белое пятно» рынка: есть три подхода (правила, одноразовый ответ LLM, цикл «слайсер оценивает — LLM корректирует»), но все готовые реализации привязаны к одному слайсеру, а фото как вход есть только у коммерческих сервисов.

Решение Как подбирает Вход Слайсер Зрелость
LLMs as Tuning Experts (CMU, 2026) Слайсер прогоняется в цикле, выдаёт оценку (время, стоимость пластика, штраф за качество) и диагностику; LLM выбирает одну проблему и предлагает правки; байесовская оптимизация настраивает ориентацию и 13 параметров LLM видит только диагностику и список допустимых правок, не геометрию Слайсер (какой именно, не уточнено), печать на Prusa i3 MK3S Исследование; на 100 деталях Thingi10k лучшая конфигурация в 78% случаев против 15% «вероятных провалов» у чат-базовых моделей (по пересказу); код не найден
slicer-copilot LLM по цели (баланс, прочность, качество, скорость, своя) предлагает правки настроек с пояснением причин; есть --dry-run .3mf Bambu Studio, цель, заметки; в LLM уходит сводка и превью пластины Только Bambu Studio Apache-2.0, экспериментальный, 12 звёзд, 7 коммитов
PrusaMCP recommend_profile Рекомендация профиля по намерению, соплу, материалу и анализу сетки; с обоснованием, опирается на базу знаний и лимиты скорости материалов STL/3MF, намерение, материал Только PrusaSlicer MIT, v1.0.0; эвристики не раскрыты
SliceHub (MIT CSAIL) Заранее оценивает время и расход материала при 16 профилях слоя × 16 масштабах; нарезает 10% и досчитывает полиномом; показывает компромиссы в Cura STL, принтер, материал, границы времени/материала Cura 3.6 plugin Прототип; без LLM, без проверки успеха печати
Cura MCP Нет встроенной логики подбора: LLM сама меняет настройки Cura; встроены ориентация и сравнение времени Ввод пользователя Cura Проприетарный

Что отличает сильный подход. Работа CMU не просит LLM «угадать» числа: проверяемый слайсер даёт объективную оценку, LLM объясняет направление поиска, а оптимизатор подбирает значения. Именно это лучший прототип архитектуры для нашего модуля подбора.

Ограничения. В CMU оценка «качества» — эвристика, физическая проверка качественная, только некоторые параметры тюнятся. Фото как вход для подбора есть только в коммерческих веб-сервисах ниже и сводится к диагностике уже дефектной печати.
