# FDM AI: вики и сравнение компонентов

Статичный сайт без сборки: `index.html`, `style.css`, `app.js`, `data.js`.

## Публикация на GitHub Pages
1. На github.com: New repository, имя например `fdm-ai-wiki`, Public, Create.
2. Add file → Upload files: перетащите ВСЕ файлы из этой папки (включая `.nojekyll`), Commit changes.
3. Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, folder `/ (root)` → Save.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/fdm-ai-wiki/`.

Файлы должны лежать в корне репозитория (index.html рядом с style.css). Свой домен: Settings → Pages → Custom domain.
